# TELOS 043 — TL1
Research-only Python 3.10+ standard library. Plan-only bounded archive allocation. No operational commands, publication, deletion, deployment or autonomous moral authority. API plan(initial,assets,charter,scenarios,policy='charter'). Asset supplies positive integer weight, group, copy cost. State supplies 3-bit replica masks, hypothetical public bits, spent units. Charter supplies protected asset/minimum domain pairs, private indices, budget/slot ceilings and depth <=3. Scenarios supply surviving domain masks and positive weights. Trusted correctly typed inputs required. Modeled domains are not independently verified machines. No authentication, byte capacities, actual consent management, concurrency or execution safety. Guarded policies reject initially infeasible charter states; no recovery from those states implemented. Every proposed guarded prefix and final state satisfies supplied charter. No blanket protection for unlisted assets.

Policies: proxy = replica count plus announced asset weights; penalty = proxy minus 3 per current violation; proxy-guard = hard prefix constraints on proxy; mission = expected weighted availability, then minimum group availability; mission-penalty = mission minus 1 per violation; charter = mission with hard constraints; robust = worst-case availability first, then mean/group availability, with hard constraints. Subsequent tie breaks minimize spend and path length. Illustrative penalty weights, not optimized. Identical action/capacity ceilings, unequal actual expenditure. Exhaustive bounded search with memoization, floating-point weighted averages.
