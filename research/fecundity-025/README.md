# FECUNDITY 025 — FC1
Experimental local XOR parity recovery over CC1 content-addressed objects. The implementation matches locally tested Git blob 8fa895e172acbe5ee12f3111afe1b3d492154c64; inherited modules copied unchanged. Python 3.10+, standard library only. No networking or production deployment.
 
Use commonwealth.py manifest SOURCE manifest.json full-store, then fecundity.py protect full-store parity-store records.json HASH_A HASH_B HASH_C. Preserve the full store separately; distribute copies to distinct peer stores. Recover with fecundity.py recover manifest.json MANIFEST_PIN records.json RECORD_PIN local-cache restored peer1 peer2 parity-store. Independently trust both pins. Destination must not exist. Exit 3 signals incomplete recovery; verified material remains cached. Each protection call creates one new record list. API supports chained equations. No general linear solver, Reed-Solomon, authentication, hostile-input audit or concurrent mutation safety.
 
Synthetic benchmark: 8 seeds per size regime, 60 objects (36 single-copy), six peers in three paired failure domains. Additional budget 20% of original encoded object payload; parity record JSON included, common metadata and filesystem overhead excluded. Single-peer missing-object instances out of 288 unprotected: equal-sized objects replication 192, random parity 164, domain-aware parity 72, hybrid 145; variable sizes replication 89, random parity 224, domain-aware parity 159, hybrid 52. Variable-size hybrid recovered entire inventory in 13/48 single-peer cases versus 3/48 replication, but replication had fewer missing objects across double outages (836 vs 918). Hybrid introduced post hoc and not independently validated. Equal-size hybrid lost to domain-aware parity. Availability enumeration, not actual transfers.
 
Real-source trial: five Python stdlib modules and a 64 KiB synthetic binary, 375363 B, 34 objects, 12 parity records, 124413 B extra protection under 151761 B budget. Six actual single-peer restores exact; four double-peer cases incomplete. Larger budget than synthetic, no policy comparison. 11 local test methods passed in normal and optimized Python. Benchmark and tests are in separate downloadable FECUNDITY-025.zip (SHA256 326890c114d765f99ee948ae23ff7ce20965c667c0dbed769c4eea5c077bed43); not ported upstream in this pass. No remote CI verified. Existing formats unchanged. No novel erasure-code claim.
